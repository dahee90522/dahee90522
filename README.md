# 황다희 (Dahee Hwang)
**Frontend & Product Engineer**

TypeScript, React, Next.js, React Native를 기반으로 완성도 높은 웹·모바일 프로덕트를 만듭니다. 디자인 시스템 아키텍처, 엄격한 타입 안정성, 렌더링 성능 최적화, 그리고 AI 에이전트를 실무에 통합한 철저한 테스트와 개발 생산성에 집중합니다.

---

### 🛠 엔지니어링 원칙 & 관심사

- **디자인 시스템 & 컴포넌트 아키텍처**: 토큰(Tokens), 프리미티브(UI), 조합 패턴(Patterns) 계층 구조의 멀티 패키지 디자인 시스템 설계. 라우터·폰트 비종속적 구조와 Next.js(SSR)·Vite(CSR) 렌더링 호환성 및 웹 접근성(a11y) 보장.
- **타입 안정성 & 데이터 아키텍처**: TypeScript와 Zod, TanStack Query를 활용한 엄격한 타입 경계 구축. Zustand 기반의 모듈화되고 예측 가능한 클라이언트 상태 관리.
- **렌더링 성능 & Core Web Vitals**: LCP/INP 등 핵심 웹 지표 개선, 렌더링 프로파일링 및 불필요한 리렌더링 제거, 번들 사이즈 최적화를 통한 체감 속도 향상.
- **크로스플랫폼 프로덕트 개발**: React Native와 Expo를 활용해 네이티브 기능 연동부터 공통 UI 로직 재사용까지 일관된 프로덕트 경험 제공.
- **AI 에이전트 기반 테스트 & 자동화**: `CLAUDE.md`로 프로젝트 컨벤션을 코드화하고, AI 에이전트를 개발 루프에 통합해 복잡한 엣지 케이스 발굴과 엄격한 테스트를 수행하여 프로덕트의 신뢰성을 검증.
